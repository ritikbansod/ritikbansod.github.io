Kview // Apache Kafka® Management UI, CLI & AI Agent Engine

Ultra-lightweight, zero-dependency Apache Kafka® cluster management web UI, high-throughput REST API, dependency-free Node.js CLI, and 16-tool Model Context Protocol (MCP) server for Claude Desktop, Cursor, and AI engineering agents.

GitHub (v1.0.0) 🚀 Release Notes 🐳 GHCR Image
// KVIEW v1.0.0 LIVE PREVIEW
Live End-to-End Cluster Topology: Dynamic SVG visualization connecting Producers → Cluster (Brokers, Topics, Partitions) → Consumers with live throughput counters.
Real-Time Cluster Dashboard: High-level KPIs, broker partition distribution balance, under-replicated / offline partition warnings, and consumer group status.
Non-Committing Data Explorer: Browse records via partition assignment seeks without rebalancing consumer groups; stream messages in real-time over Server-Sent Events (SSE).
16-Tool Model Context Protocol (MCP) Server: Empowers AI agents in Claude Desktop, Cursor, and terminals to inspect Kafka brokers, analyze partition lag, and test produce payloads over JSON-RPC.
// PILLAR 01

Non-Committing Safe Reads

Direct partition assignment and explicit seeks by earliest, latest backwards seek, or timestamp — never joins consumer groups or perturbs production offsets.
